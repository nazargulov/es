TextoVivo Privacy Policy

Last updated: November 14, 2026. This policy covers the Chrome extension «AI Detector & Text Humanizer - TextoVivo» and its server. Data controller: the developer of TextoVivo, contact u9603656505@gmail.com.

1. Data collection: what we collect

  • Text you submit (website content): the text you paste, or select on a page and send through the TextoVivo context menu item, and your answers to the humanizer questions.
  • Install ID: a random code created on install. It does not contain your name or email.
  • IP address (location): received by the server with every request. We do not derive or store a precise location.
  • Usage data (user activity): which feature you use, language, time zone, version, plan, approximate text size and the result, sent to Google Analytics with a random analytics ID. Never the text itself. No clicks, keystrokes or mouse movement outside the extension panel.
  • If you pay (personally identifiable information): email address, plan and license key. Card details are collected by Stripe; we never see them.
  • Authentication information: the license key of a paid plan, and your own API key (Gemini or OpenRouter) if you paste one. Your API key is kept in your browser and sent through our server with each request only to call that provider under your account. The server does not store it.

We do not collect browsing history and the extension does not read the pages you visit. It receives only the text you paste or the text you select and choose to send.

2. Data handling: how we use it

  • Text: to analyze or rewrite it and return the result to you.
  • Install ID and IP address: to enforce free-use limits and prevent abuse.
  • Usage data: to see which features are used and fix bugs.
  • Email and license: to activate the paid plan and provide support.
  • Texts saved with «Help improve the detector with my texts» on (see section 3): only to measure and tune detection.

We do not sell user data, do not use or transfer it for advertising, creditworthiness or any purpose unrelated to the extension's single purpose, and do not use your texts to train third-party models. Our use of data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

3. Data storage: where and for how long

  • Submitted text: with «Help improve the detector with my texts» off, the text is processed and discarded when the request ends. With it on (on by default; shown with an off switch before your first check, and in Settings), we keep the text, the result and your answer to «Who wrote this text?» for up to 180 days on EU servers (Cloudflare D1), linked to the install ID. Deleted automatically after 180 days.
  • Text hash and result: 7 days, so the same text returns the same result. The text cannot be rebuilt from the hash.
  • IP address: 2 days. Free-use counter per install: up to 400 days.
  • Email, plan and license: while the plan is active and afterwards, so the license can be restored; deleted on request.
  • In your browser (Chrome local storage): install ID, analytics ID, counter, license, your API key, settings and the last draft. Removed when you uninstall the extension.

All data travels over HTTPS. The server runs on Cloudflare and only the developer can access the data.

4. Data sharing: who receives it

  • AI model provider: the text is sent to OpenRouter (and the model it routes to) to produce the analysis or rewrite; with your own key, to Google Gemini or OpenRouter under your account. They process it only to return the response.
  • Cloudflare: hosts the server and the database.
  • Google Analytics: receives the usage data.
  • Stripe: processes payments.

We share data with no one else, unless required by law.

5. Your rights and choices

You can turn off text saving in Settings at any time. You can request access, correction or deletion of your data, including saved texts, by writing to u9603656505@gmail.com. The extension is not directed at children under 13. If this policy changes, the date above is updated.

Política de privacidad de TextoVivo

Última actualización: 14 de noviembre de 2026. Se aplica a la extensión de Chrome «TextoVivo» (detector de IA y humanizador de texto) y a su servidor. Responsable: el desarrollador de TextoVivo, contacto u9603656505@gmail.com.

1. Qué datos recogemos

  • Texto que envías: el texto que pegas o seleccionas y pides revisar o reescribir, y tus respuestas a las preguntas del humanizador.
  • Identificador de instalación: un código aleatorio creado al instalar. No contiene tu nombre ni tu correo.
  • Dirección IP: la recibe el servidor con cada petición.
  • Datos de uso: qué función usas, idioma, zona horaria, versión, plan, tamaño aproximado del texto y resultado, con un identificador aleatorio de analítica (Google Analytics). Nunca el contenido del texto.
  • Si pagas: correo electrónico, plan y clave de licencia. Los datos de la tarjeta los recoge Stripe; nosotros no los vemos.
  • Datos de autenticación: la clave de licencia del plan de pago y tu propia clave de API (Gemini u OpenRouter), si la pegas. Tu clave de API se guarda en tu navegador y pasa por nuestro servidor en cada petición solo para llamar a ese proveedor con tu cuenta. El servidor no la guarda.

  • El texto, para analizarlo o reescribirlo y devolverte el resultado.
  • El identificador y la IP, para aplicar los límites de uso gratis y evitar abusos.
  • Los datos de uso, para saber qué funciones se usan y corregir errores.
  • El correo y la licencia, para activar el plan de pago y darte soporte.
  • Los textos guardados con la opción «Ayudar a mejorar el detector» (ver punto 3), solo para medir y ajustar la detección.

No vendemos datos, no los usamos para publicidad ni para decidir sobre créditos, y no usamos tus textos para entrenar modelos de terceros. El uso de los datos cumple la Política de datos de usuario de Chrome Web Store, incluidos los requisitos de uso limitado.

3. Dónde y cuánto tiempo se guardan

  • Texto enviado: con la opción «Ayudar a mejorar el detector con mis textos» apagada, se procesa y se descarta al terminar. Con la opción encendida (viene encendida; te la mostramos antes de la primera revisión y puedes apagarla ahí o en Ajustes), guardamos el texto, el resultado y tu respuesta a «¿Quién escribió este texto?» hasta 180 días en servidores de la UE (Cloudflare D1), vinculados al identificador de instalación. Se borran automáticamente a los 180 días.
  • Huella del texto (hash) y resultado: 7 días, para devolver el mismo resultado si revisas el mismo texto. Con la huella no se puede reconstruir el texto.
  • IP: 2 días. Contador de usos gratis por instalación: hasta 400 días.
  • Correo, plan y licencia de pago: mientras el plan esté activo y después, para poder restaurar la licencia; se borran si lo pides.
  • En tu navegador (almacenamiento local de Chrome): identificador de instalación, contador, licencia, tu clave de API, ajustes y el último texto en edición. Se borran al desinstalar la extensión.

Todo viaja cifrado (HTTPS). El servidor funciona en Cloudflare y solo el desarrollador tiene acceso a los datos.

4. Con quién se comparten

  • Proveedor de modelos de IA: el texto se envía a OpenRouter (y al modelo que enruta) para generar el análisis o la reescritura; si usas tu propia clave, a Google Gemini u OpenRouter con tu cuenta. Lo procesan solo para devolver la respuesta.
  • Cloudflare: aloja el servidor y la base de datos.
  • Google Analytics: recibe los datos de uso.
  • Stripe: procesa los pagos.

No compartimos datos con nadie más, salvo que lo exija la ley.

5. Tus derechos y opciones

Puedes apagar el guardado de textos en Ajustes en cualquier momento. Puedes pedir acceso, corrección o borrado de tus datos, incluidos los textos guardados, escribiendo a u9603656505@gmail.com. La extensión no está dirigida a menores de 13 años. Si cambiamos esta política, actualizaremos la fecha de arriba.
